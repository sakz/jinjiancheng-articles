# 天玑全集静态阅读站实施记录

目标：将 `md/天玑全集/` 全部文章建成可部署到 Vercel、可检索的静态网站，并以详细总结和信息图呈现投资、育儿、成长与商业理念。

## 实现方式

构建使用 Node.js 与 markdown-it；浏览器只运行原生 HTML、CSS 和 JavaScript。823 篇文章分别生成独立 HTML 页面，轻量目录与完整检索索引分开输出。第一次全文检索时由 Web Worker 载入索引，后续复用。三个目录作为公众号来源，不能仅凭目录认定为三个作者。

## 完成与核对

- [x] `scripts/build.mjs` 读取全部源 Markdown，保留稳定 ID、发布日期、标题、原文链接、正文与归档留言；不修改源文件。
- [x] 三个来源的条目数为金渐成 484、天机奇谈 324、生玑伯伯 15，合计 823，与源文件集合一致。
- [x] `site/templates.mjs` 生成首页、档案、823 个文章页面、四个理念栏目、关于页面及 404 页面，共 831 个 HTML 页面。
- [x] `site/app.js` 和 `site/search-worker.js` 提供多关键词同时匹配、公众号与年份筛选、三种检索范围、摘要高亮和分页；查询条件保存在 URL 中。
- [x] `content/insights.mjs` 整理 50 个展开主题：投资 13、育儿 15、人生与成长 12、商业与社会 10。每项标注可点击的文章出处，构建时检查引用唯一匹配。

- [x] 使用官方 npm registry 完成干净安装，依赖审计报告 0 个已知漏洞。
- [x] 检查 831 个 HTML 页面的本地路径与锚点，检查源文件覆盖集合、50 个主题的出处和 JavaScript 语法，`git diff --check` 通过。
- [x] Worker 检索结果与独立全文扫描一致；核对多关键词和来源/年份筛选、OCR 字符规范化、空结果、留言隔离和索引仅加载一次。

## 交付边界

完成本地构建和浏览器核对，未提交、推送或向 Vercel 发布。全文索引约 14.50 MiB（gzip 约 6.36 MiB），首次全文检索需加载；仅标题检索只使用目录。原文图片沿用微信图床地址，不能保证外部图床持续可用。新增文章自动进入构建，理念总结仍需阅读后更新。
