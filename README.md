# 微信文章归档

独立保存微信公众号文章正文与评论，供采集工作台写入、[tomcattravel.com](https://tomcattravel.com) 只读构建。仓库名称为 `jinjiancheng-articles`，实际包含下列全部文章源，不仅限于金渐成。

## 目录

- `md/汤姆喵的奇妙旅行/`
- `md/天玑全集/金渐成/`
- `md/天玑全集/天机奇谈/`
- `md/天玑全集/生玑伯伯/`
- `md/猫笔刀/`
- `pdf/`：后续手动导出 PDF 的保存目录（当前基线没有 PDF）

Markdown 保留正文、原文链接、现有评论与回复以及已有的消失标记，不修改原始导出措辞。文件名沿用 `[发布日期]标题.md`；初始迁移额外保留一份已归档 DOCX。文章条目数与去重后的网页数可能不同。

## 数据流

```text
wechat-article-monitor → 本仓库 md/、pdf/ → GitHub main
                                            ↓
                                 tomcatTravel 导入与网站构建
```

采集工作台默认保存到 `~/Documents/git/jinjiancheng-articles`，可用服务端环境变量 `ARTICLE_REPO_PATH` 配置绝对路径。保存、Git 推送和 Markdown 历史恢复使用同一目标；推送默认分支为 `main`。网站默认读取同级仓库，生产部署固定文章 commit 进行构建，并在文章更新后自动重建。

人工补录评论的草稿、预览及发布功能尚未实现；将来确认发布的补录应同时持久化到本仓库，不应只修改网站生成文件。

## 图片与网站缓存

Markdown 中的图片链接沿用原始文件；网站生成的 WebP 图片、Astro 页面和评论 JSON 仍由 `tomcatTravel` 管理，不是本仓库的原始输入。克隆本仓库不等于获得完整离线图片包。请修改原始文章或经审核发布的补录数据，不要用网站生成文件反向覆盖原始归档。

网站部署同时跟踪两个仓库；文章仓库更新不要求网站代码新增提交。可访问 [article-revision.txt](https://tomcattravel.com/article-revision.txt) 核对网站当前采用的文章 commit，不能仅凭 Git 推送成功就认定网站已更新。

## 初始迁移

从 `tomczhang/tomcatTravel` 的 `a3e1ad0` 对应工作区迁移 **894 份 Markdown 和 1 份 DOCX**。完整源提交号及逐文件 SHA-256 见 [`migration-manifest.json`](./migration-manifest.json)。此清单仅记录初始迁移基线，后续修改以 Git 提交历史为准。

迁移采用干净的初始提交，不导入旧网站仓库完整 Git 历史，不含网站代码、账户数据库、Cookie 或运行密钥。正文与现有评论原样复制；仅存在于旧 Git 中间版本、没有出现在当前文件的内容需回溯旧仓库历史。

## 来源与权属

文章、评论及相关资源的权利归各自权利人所有。归档与公开访问不代表获得转载或再分发许可；本仓库不对第三方文章、评论统一授予开源许可。请保留原文链接及署名，并自行确认使用授权。历史消失标记只反映采集记录，不确认删除原因。

这是公开 Git 仓库：不要提交草稿中的私密说明、登录信息或其他敏感数据。删除当前文件不能自动移除公开 Git 历史或他人的克隆副本。
