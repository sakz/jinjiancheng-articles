# 写在阿里全面禁用 Claude Code 之际，A / 终将反噬其身

> 利益相关，本人在阿里工作，持有大量阿里股票。观点仅为个人主观意见。

今天想必内外消息都爆了，阿里全面禁用 Claude Code，就我自己下午就已经弹了三四次弹窗了，云壳（阿里内部安全软件）的给我的警告就是让我抓紧卸载。

据我自己的观察来看，公司内部的观点也是以反对卸载的观点居多。很多人并不能理解为什么如此粗暴强硬的禁止大家使用Claude Code。

毋庸置疑， Anthropic 目前在编程领域还是独占鳌头。Claude Code + Fable 5的组合确实有当仁不让的编程能力。

仅以我而言， 我使用 Claude Code 编程消耗的 token 大概是 Codex 消耗 token 的五倍以上。以我的专业领域前端而言，Opus 4.8 的前端审美能力也远超过 GPT 5.5。

过去大家都已经熟悉并且习惯使用了 Claude Code + Opus 的这样的组合来获得**最佳的编程体验**。贸然改变这种习惯，肯定是不适应的。

但是我这次非常想旗帜鲜明地站公司的决定。尽管我一开始也略有诧异，但是我仔细一想之后，我觉得**禁用这个决定非常的果断且具有智慧**。

可能还有些读者还不太清楚前情提要，不如让我给大家简单的梳理一下。

首先是 6 月 30 日，有开发者逆向 Claude Code 后爆出来，Claude Code 会在使用非官方 API endpoint 的时候，根据代理域名、系统时区等信息，在 system prompt 里用不可见或近似 Unicode 字符做标记。这个事情迅速在 Hacker News、Reddit 和技术媒体上炸开了锅。

随后 Anthropic 的 Claude Code 团队工程师 Thariq Shihipar 在 X 上回应，说这是他们 3 月推出的一个实验，目的是防止未授权转售商滥用账号，以及防止模型蒸馏；并表示团队已经有了更强的防护措施，这个旧机制会在后续更新中移除。

既然已经删除了，为什么大家还如此的群情激奋呢？甚至今天公司还果断做出了再也不使用 Claude Code  的这样的决定。

**因为这已经不是这家公司第一次出现这样的事情了**。

上一次是 Claude Fable 5 发布后的“静默降级”争议。Anthropic 一开始对部分它认为涉及高风险领域、模型蒸馏或者前沿 AI 研发的请求，采用了降级或重路由的方式，让用户可能在不充分知情的情况下拿到较差的模型结果。后来舆论反弹，Anthropic 承认“做错了权衡”，改成在拒绝或重路由时显式告知用户。

这本质上是剥夺了用户的选择权，我花的就是最贵的模型的费用，我理应享受到最贵模型的服务，而不是你认为你是为了我好，我冬天就必须要穿个秋裤。

而且 Anthropic 这家公司在 Claude Code 中出现过非常严重的输出污染问题。想必用多了 Opus 4.8 的同学，或多或少都遇到过类似的诡异时刻：聊着聊着，模型突然说当前上下文里出现了一段和任务完全无关的异常注入，导致这次返回不可信，甚至只能停止继续工作。

比如说那天我就遇到了这样一个问题，我的Opus 4.8跑着跑着，突然输出了一段它的返回中收到了一段“I notice you're seeing corrupted tool output... Let me be transparent...”，然后任务就停了。

我一开始很诧异，我就去查，我发现我这个问题不是一个个例现象，而是广泛出现在Opus 4.8的。Github上这种issue不要太多，Linuxdo中也有相关的帖子讨论。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/n5wVaZTytOibqn09HzsWrnnTiaXfafyoRwDjhAwwq3ibqJw8VIvCQwoAt4k5GLqJQK7aGqYOTvUGJv1CAScomNaRs1uzLibQXFYUzkPjXXVxhO0/640?wx_fmt=png&from=appmsg)

Anthropic 没有回应，但是根据模型的返回，这也很像是一种防蒸馏的措施。

我当然没有去蒸馏它了。我相信可能就是它的这个措施判断失误了，所以给我添加了这么一段。但是我觉得这个问题的核心是，**Anthropic 这个公司的企业文化它有问题**。

防蒸馏应该怎么做？当我发现用户在尝试蒸馏我的时候，我可以封禁他的账号，也可以显示的提示中断服务，甚至锁定机器 IP，弹 KYC 信息验证。但是你不能悄咪咪地标记用户，给用户打标签，也不应该给用户的返回注水。

这和携程标记那些高净值的用户，让高净值的用户去住酒店的时候多花钱，又有什么区别呢？

做出这种事的本质原因就是**没有把用户放在尊敬的位置上，没有把用户放在眼里**。

真正受人尊敬的公司，都是把用户放在第一位的。比如说苹果，是苹果造不出车吗？显然不是，而是苹果认为它造的车没有办法给用户提供足够的价值，所以它才不造。这才是苹果成为最受人尊敬的公司之一。

段永平说过，买股票就是买公司，**一个企业真正的核心竞争力就是企业文化**。

Anthropic 这种偷偷摸摸的打标方式就非常的不大气，甚至用个不好听的词，有点下作。说到这里，我又想起了当年百度的魏则西事件和血友病吧被卖事件。

百度难道不知道它是在吃人血馒头吗？但是为了自己的营收 KPI，就可以罔顾用户的利益，最终自然受到用户的反噬。

一个魏则西倒下去，一万个魏则西站起来。我就是从血友病事件开始，不再使用百度的。说实在的，要不是为了给群友们分享机哥的文章，我甚至不会去买百度网盘。这也是为什么最开始我只提供夸克网盘的原因。

《孟子·离娄下》里说，君之视臣如手足，则臣视君如腹心；君之视臣如犬马，则臣视君如国人；君之视臣如土芥，则臣视君如寇雠。

**公司怎么对待你的用户，你的用户就会怎么对待你**。

今天， Anthropic 确实在编程领域占有第一的位置，但是这个位置和第二的差距已经被极大地缩短了。

三年半以前，当 GPT-3.5 随 ChatGPT 横空出世的时候，恕我直言，除了 GPT-3.5，其他的都不能用。。今天哪怕是不用 Anthropic 的产品，我们依然能编写出很好的 Vibe Coding 作品。只不过是效率低些。

说到效率，Anthropic 这种看人下菜碟，给自己家产品注水的行为，就是在降低自己用户的效率。

我花着最贵的 token 的钱，是为了追求最高的任务解决效率。如果我被打了标签，花着最贵 token 的钱，享受着差一等模型的效率，这又算什么事情呢？

我请问，商业精神在哪里？契约精神又在哪里？

你当然可以说，Anthropic 早已经说过，我们不再向中国大陆境内提供服务，你本身就不是我的用户。

但我想说，你收了我的钱，我们的合约就存在。如果你认为我不应该使用你们的产品，那要不然就别收钱，要不然就明明白白地把我的账户禁掉，或者是直接拒绝我账户的服务。这才是一个光明正大的王道处世方法。

今天是对我打标签，给我注水，明天就有可能以百分之五的概率给我返回更差的模型的结果，甚至故意窜改我的结果，或者是偷我电脑上的信息。

忠诚不绝对，就是绝对不忠诚。你没有办法期待一个惯常出轨的人，去当模范夫妻。

《六国论》里说，今日割五城，明日割十城，然后得一夕安寝。起视四境，而秦兵又至矣。然则诸侯之地有限，暴秦之欲无厌，奉之弥繁，侵之愈急。

不仅仅阿里在做这样的事情。其实硅谷的很多公司都已经在做相应的事情了。

我们大家不知道的是，硅谷现在有很多的公司都在使用智谱的模型。做自己的私有化部署。

为什么呢？就是因为 Anthropic 老做小动作。大家认为，今天你可以给我差的模型，明天你就有可能去偷窃我的商业数据。为了避免这种可能性，所以我直接就部署我自己的私有模型。

Anthropic 做这件事情还少吗？4 月 14 日，Anthropic 首席产品官 Mike Krieger 辞去 Figma 董事会职务；4 月 17 日，Claude Design 横空出世。

这不禁令人遐想。当然，我并没有实际的证据。你可以说我这是无端的猜测。但我想，今天，Anthropic 去给用户打标的这件事情，绝不应该被轻轻地放下了。

它至少应该先应该像携程一样，被进行惩罚。当然了，今天没有人能对他做这件事情。但是我相信互联网是有记忆的。**Anthropic 也终将会为一次次侵犯用户隐私的事情付出代价**。

这件事情，且不说所有的国人都在 Anthropic 的禁止名单上。就算只惩治大厂，只惩罚阿里。

德国牧师马丁·尼莫拉后来忏悔说，最初他们抓社会主义者，我没有说话；后来他们抓工会成员，我没有说话；后来他们抓犹太人，我没有说话；最后他们来抓我，已经没有人能为我说话。

综上，不管是出于公司的利益，还是出于自己的利益。我都支持公司的决定。

最后我还想说，今日断腕，明日长骨。**Skill可以重新配，效率可以再追，选择权不能轻易放弃，底线不能被突破哪怕一次**。

当今的世界，不是三年半之前的 AI 世界。哪怕是三年半以前的 AI 世界，那时候称霸世界的好像还叫 OpenAI。没有了张屠户，照样吃带毛的猪。

A / 就是 A /，被封的还不够吗。种一棵树，最好的时间就是十年前，其次就是现在。没时间再浪费了，让我们和Claude Code告个别吧。

以上就是我的观点。
